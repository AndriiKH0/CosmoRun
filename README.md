 O projekcie
 
CosmoRun to kosmiczna gra zręcznościowa na Androida, w której gracz steruje statkiem kosmicznym za pomocą żyroskopu telefonu. Gra łączy retro pikselową grafikę z nowoczesnym sterowaniem, tworząc wyjątkowe doświadczenie rozgrywki.

 Mechanika gry

Sterowanie żyroskopem: Przechylaj urządzenie w lewo i prawo, aby manewrować statkiem kosmicznym
Przyspieszenie: Dotknij ekranu, aby aktywować tryb przyspieszenia
Unikaj meteorytów: Różne typy meteorytów będą próbowały zniszczyć twój statek
Zbieraj paliwo: Aby kontynuować lot, musisz zbierać zbiorniki z paliwem
Super-paliwo: Specjalny rodzaj paliwa, który pozwala aktywować tryb przyspieszenia
Serca: Dają dodatkowe życie twojemu statkowi

 Cechy gry

Intuicyjne sterowanie: Żyroskop do manewrowania, dotknięcie ekranu do przyspieszania
Progresywna trudność: Gra staje się trudniejsza wraz ze wzrostem wyniku
Pikselowa grafika: Styl retro tworzy atmosferę klasycznych kosmicznych arkad
Zapis w chmurze: Twoje rekordy są zapisywane w chmurze przez Firebase
Fizyka ruchu: Realistyczne przyspieszenie i inercja statku

 System rekordów
 
Gra wykorzystuje Firebase do zapisywania twoich rekordów. Każde urządzenie zapisuje swój najlepszy wynik, pozwalając na rywalizację z innymi graczami.

 Wymagania

Android 6.0 (poziom API 23) lub wyższy
Urządzenie z żyroskopem
Połączenie z internetem do zapisywania rekordów

 Instalacja

Pobierz plik APK z wydań
Zainstaluj APK na swoim urządzeniu
Zezwól na dostęp do czujników urządzenia przy pierwszym uruchomieniu

 Rozwój
 
Projekt został opracowany z wykorzystaniem:

Kotlin
Jetpack Compose
Firebase Realtime Database
Firebase Authentication
ExoPlayer dla efektów tła
